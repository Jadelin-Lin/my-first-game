HOW TO PLAY

▸ 键盘操作（PC）

左右换道← → / A D
跳跃 / 二段跳↑ / W / 空格
滑铲↓ / S / Shift
暂停 / 恢复Esc / P

▸ 触屏操作（手机）

在屏幕上向左右滑 = 换道，向上滑 = 跳跃（空中再滑一次 = 二段跳），向下滑 = 滑铲；也可直接使用屏幕下方的四个虚拟按键。

▸ 障碍物怎么过

矮障碍（石堆 / 木箱 / 珊瑚）跳过去；悬空横杆（门楣 / 雨棚 / 水母）滑铲钻过去；整条车道被封死（方尖碑 / 电话亭 / 石柱）只能换道绕开。撞到会掉 1 条命，护盾可以抵挡一次。

▸ 收集与道具

金币 / 小鱼币加分，小鱼币价值更高
磁铁一段时间内自动吸取金币
